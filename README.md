# סיור מחסן תלת־מימד 🏭

מערכת הדרכה לעובדים: הדמיית תלת־מימד של המחסן שאפשר "ללכת" בה כמו במשחק, עם התמונות האמיתיות של המדפים, חיפוש מוצרים, והקלטת סרטון הדרכה לשליחה בווצאפ.

**בלי שרת, בלי התקנות** — אתר סטטי שרץ בכל דפדפן, גם בטלפון.

## הפעלה מקומית

צריך שרת סטטי פשוט (פתיחת הקובץ ישירות לא תעבוד בגלל טעינת מודולים):

```bash
python3 -m http.server 8000
```

ואז נכנסים ל־http://localhost:8000

אפשר גם לפרסם את הריפו ב־GitHub Pages ולקבל כתובת קבועה שנפתחת מכל טלפון.

## איך משתמשים

| פעולה | מחשב | טלפון |
|---|---|---|
| הליכה | WASD או חצים | ג'ויסטיק בפינה |
| סיבוב מבט | לחיצה על המסך + עכבר | גרירת אצבע |
| חיפוש מוצר | תיבת החיפוש למעלה | תיבת החיפוש למעלה |
| הקלטת סרטון | כפתור "הקלטה" | כפתור "הקלטה" |

- **חיפוש**: מקלידים שם מוצר → המערכת מקפיצה אתכם למדף ומדליקה עליו עמוד אור ירוק.
- **הקלטה**: לחיצה מתחילה, לחיצה נוספת עוצרת. הקובץ יורד למכשיר (mp4 בדפדפנים עדכניים) — ומהטלפון אפשר לשתף ישירות לווצאפ.

## עדכון המחסן

כל התוכן יושב בשני מקומות בריפו:

- **`data/layout.json`** — מבנה המחסן: מעברים, מדפים, מוצרים.
- **`photos/`** — התמונות של חזיתות המדפים ([הוראות צילום](photos/README.md)).

### דרך מצב העריכה (מומלץ)

1. לוחצים ⚙️ באתר — נפתח פאנל עריכה בעברית.
2. מוסיפים/עורכים מדפים, בוחרים תמונות, מתייגים מוצרים. הכל מוצג מיד בתלת־מימד ונשמר כטיוטה בדפדפן.
3. בטאב "שמירה": מייצאים `layout.json` מעודכן → מחליפים את הקובץ ב־`data/`, ומעתיקים את התמונות החדשות ל־`photos/` (יש רשימה מסודרת בפאנל).
4. עושים commit — או פשוט שולחים את הקבצים ל־Claude ומבקשים לעדכן.

### עריכה ידנית

אפשר לערוך את `data/layout.json` ישירות — כל שדה חסר מקבל ברירת מחדל, ומדף בלי תמונה מוצג עם איור ממלא־מקום.

## מבנה הקוד

```
index.html          שלד הדף (עברית, RTL)
css/style.css       עיצוב הממשק
js/main.js          אתחול ולולאת רינדור
js/scene.js         בניית המחסן בתלת־מימד
js/controls.js      הליכה והתנגשויות (מקלדת/עכבר/מגע)
js/search.js        חיפוש מוצרים וניווט אליהם
js/recorder.js      הקלטת וידאו של הסיור
js/editor.js        מצב עריכה וייצוא
js/textures.js      טעינת תמונות + ממלאי מקום
js/data.js          טעינת/שמירת נתונים
vendor/             Three.js (מקומי, בלי תלות ברשת)
```
