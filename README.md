# 💍 אתר גלריה לחתונה

אתר סטטי, אלגנטי ומינימליסטי, להצגת תמונות החתונה ושיתופן בלינק אחד.
ללא שרת, ללא בנייה מורכבת — רק HTML / CSS / JavaScript.

כרגע מוצגות **תמונות הדגמה**. החליפו אותן בתמונות שלכם בשני צעדים פשוטים.

---

## ✨ מה יש באתר
- **מסך פתיחה** עם שמותיכם והתאריך
- **גלריה רספונסיבית** (masonry) עם טעינה עצלה — מתאימה לאלפי תמונות
- **סינון לפי קטגוריות**: הכנות · חופה · קבלת פנים · ריקודים · משפחה · רגעים
- **תצוגת Lightbox**: חצים, מקלדת (← →, Esc), החלקה במובייל, מונה תמונות וכפתור הורדה
- תמיכה מלאה ב-RTL ועברית, ונגישות (כולל `prefers-reduced-motion`)

---

## 🚀 איך מוסיפים את התמונות שלכם

### צעד 1 — לארגן את התמונות בתיקיות לפי קטגוריה
בתוך התיקייה `photos/` צרו תת-תיקיות, ושימו בכל אחת את התמונות המתאימות:

```
photos/
  preparations/   ← הכנות
  ceremony/       ← חופה
  reception/      ← קבלת פנים
  dancing/        ← ריקודים
  family/         ← משפחה
  friends/        ← חברים
  moments/        ← רגעים (גם תמונות ישירות ב-photos/ ייכנסו לכאן)
```

> אפשר להשתמש רק בחלק מהקטגוריות. שמות הקבצים יכולים להיות כל דבר (IMG_1234.jpg וכו').
> נתמכים: `jpg, jpeg, png, webp, avif, gif, svg`.

### צעד 2 — לייצר את רשימת התמונות
מהתיקייה הראשית הריצו:

```bash
node scripts/build-gallery.mjs
```

הסקריפט סורק את `photos/`, מעדכן את `photos/manifest.js` עם כל התמונות שלכם,
ומדפיס סיכום (כמה תמונות בכל קטגוריה). רעננו את הדפדפן — וזהו. 🎉

> תמונות ההדגמה שבתיקייה `photos/demo/` לא נכללות. אפשר למחוק את התיקייה הזו כשתסיימו.

## 🖼️ טיפ חשוב ל-4000 תמונות
קבצים ישירות מהמצלמה כבדים (5–10MB כל אחד). לאתר חלק ומהיר, כדאי **לכווץ** קודם.
דוגמה עם ImageMagick (מקטין ל-2000px רוחב ואיכות 82%):

```bash
# מתוך תיקיית התמונות המקורית
mkdir -p resized
for f in *.jpg; do
  magick "$f" -auto-orient -resize '2000x2000>' -quality 82 "resized/$f"
done
```

אפשר להעלות את כל המקור באיכות מלאה לשירות נפרד (Google Photos / Drive) ולקשר אליו,
ולהשתמש באתר הזה כ"חלון ראווה" יפה עם המבחר הטוב ביותר.

## 📝 התאמה אישית
ערכו את `index.html`:
- **שמות**: השורה עם `id="names"` (החליפו את `הכלה` בשם)
- **תאריך**: השורה עם `id="date"`
- **טקסט פתיחה / כותרת תחתונה**: בתוך `<header class="cover">` ו-`<footer>`

צבעים, גופנים ומרווחים — בקובץ `css/style.css` (החלק `:root` למעלה).

## 🔒 פרטיות וסיסמה
האתר מוגן ב**מסך כניסה עם סיסמה**. הסיסמה שמורה כ-hash (SHA-256) ולא כטקסט גלוי,
והכניסה נזכרת לאורך הסשן בדפדפן.

### ⚠️ חשוב להבין — זה "מנעול רך"
מכיוון שזה אתר סטטי, מסך הסיסמה מרתיע מבקרים מזדמנים אבל **אינו הגנה מלאה**:
מי שמכיר את הכתובת הישירה של קובץ תמונה עדיין יכול לפתוח אותו.

### להחלפת הסיסמה
חשבו hash חדש והחליפו את הערך של `PASS_HASH` בקובץ `js/lock.js`:
```bash
node -e 'console.log(require("crypto").createHash("sha256").update("הסיסמה-החדשה").digest("hex"))'
```

### לפרטיות אמיתית (מומלץ אם התמונות רגישות)
הפעילו הגנת סיסמה **ברמת האירוח** — אז גם הקבצים עצמם חסומים:
- **Vercel**: Project → Settings → Deployment Protection → Password Protection
- **Netlify**: Site settings → Access control → Password protection
- אפשר לשלב: גם הגנת אירוח וגם מסך הכניסה היפה של האתר.

> מסך הסיסמה דורש חיבור מאובטח (https) או `localhost` כדי לאמת — כך עובד Web Crypto בדפדפן.
