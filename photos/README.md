# תיקיית תמונות המחסן

לכאן מעלים את התמונות שצילמתם במחסן — תמונה לכל חזית מדף.

## איך מצלמים נכון

- עומדים מול המדף, במרכז, ומצלמים את כל החזית שלו בתמונה אחת.
- רצוי בתאורה טובה ובלי אנשים שמסתירים.
- מומלץ להקטין תמונות ל־**רוחב 1600 פיקסלים לכל היותר** לפני ההעלאה (תמונות ענק מאיטות את הטעינה בטלפון).

## שמות קבצים

שם הקובץ צריך להתאים למה שמוגדר ב־`data/layout.json`. ברירת המחדל:

```
photos/A1-front.jpg   ← חזית מדף A1
photos/A2-front.jpg   ← חזית מדף A2
photos/B1-back.jpg    ← גב מדף B1 (אם מוגדר)
```

אפשר גם לבחור תמונה דרך מצב העריכה באתר (⚙️) — ואז שם הקובץ שנבחר יישמר אוטומטית ב־layout, ורק צריך להעתיק את הקובץ עצמו לתיקייה הזו.

## עדכון תמונה

כדי לעדכן מדף שהשתנה — פשוט מחליפים את הקובץ באותו שם. ההדמיה תציג את התמונה החדשה בטעינה הבאה.

מדף שאין לו תמונה (או שהקובץ חסר) יוצג עם איור ממלא־מקום ושם המדף — שום דבר לא נשבר.
